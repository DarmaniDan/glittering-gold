### <ins>**PATCHING INSTRUCTIONS:**</ins>

You will need:
- A clean Heart Gold (USA) ROM (not included)
- xdeltaUI (not included)
- Glittering Gold **[VERSION]**.xdelta file (included)

-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=-

**DOWNLOADING:**

  1. Go to the ``Releases`` tab and find the latest release. Download the ``.zip`` file included there. **RELEASES** >>>>>>
     
  2. Open the file in your file viewer of choice and extract the contents.

**PATCHING:**

  1. Open xdeltaUI

  2. Make sure you are in the "Apply Patch" tab

  3. For "Patch", click Open and select the file named "Glittering Gold **[VERSION]**.xdelta"

  4. For Source File, click Open and select your clean Heart Gold (USA) ROM

  5. For "Output File" choose a location to save the ROM and name it "Glittering Gold.nds"

  6. Click "Patch"
